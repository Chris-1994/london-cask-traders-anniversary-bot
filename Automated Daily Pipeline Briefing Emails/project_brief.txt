Project Brief
Automated Daily Pipeline Briefing Emails
London Cask Traders
Background
London Cask Traders is a whisky cask investment company. The sales manager oversees a team of Account Managers in HubSpot. Each working day the manager produces a personalised pipeline briefing email per rep — pulling live HubSpot data on priority deals, stale deals, uncontacted leads, and their month-to-date closed-won figure. The goal of this project is to automate this end-to-end so it runs every weekday morning without manual intervention.
Goal
Build an automation that runs every weekday at 7:30 AM Europe/London time, pulls each Account Manager’s data from HubSpot, generates a personalised briefing email using the Anthropic Claude API, and creates a Gmail draft (or auto-sends, configurable) addressed to that rep.
Trigger
Schedule trigger: Monday to Friday, 7:30 AM Europe/London timezone.
Workflow Logic
Step 1 — Get the rep list dynamically from HubSpot
Do not hardcode the list of reps. Instead, query the HubSpot Account Managers team (team ID 163861030) at the start of each run and pull all current members. This means when reps join or leave the team, the automation adapts automatically with no code changes.
For each member, retrieve: ownerId, firstName, lastName, and email. The email comes from the HubSpot Users object via the hs_email property — owner search alone won’t return it, so the workflow needs a follow-up call to fetch user details.
Step 2 — For each rep, pull from HubSpot:
Open deals (top 3 to 5 by value or closest close date) for the priority calls section. Filter: hubspot_owner_id = {ownerId} and hs_is_closed = false.
Stale deals — same filter as open deals, but with closedate in the past, or notes_last_contacted older than 60 days.
Uncontacted leads — contacts where hubspot_owner_id = {ownerId} and notes_last_contacted is empty. Sort by createdate descending. Limit 15.
Month-to-date closed-won total — deals where hubspot_owner_id = {ownerId}, dealstage is in ["2563529956", "2601372909", "closedwon"], and closedate is in the current calendar month. Sum the amount field.
HubSpot pipelines in use: default and 1884973302.
Closed-won stage IDs: 2563529956, 2601372909, closedwon.
Step 3 — Send to Claude API
Anthropic Claude API, model claude-sonnet-4-7 (sufficient for this task and cost-effective).
The prompt should include:
The rep’s first name
Their MTD closed-won figure and percentage of the £35,000 monthly target
Days remaining in the current month
The 3 priority calls with deal name, value, HubSpot link, and a short “why” reason
The stale deals list (up to 10 highest-value)
The uncontacted leads list (up to 15 most recent, with names, phone numbers, and assignment age)
Claude returns a fully-formed HTML email body following the structure in the attached example.
Step 4 — Create Gmail draft
Or auto-send, configurable via toggle. Email is addressed to the rep’s email with the Claude-generated HTML body.
Step 5 — Logging and error handling
If any step fails for one rep, log the error and continue with the others. Send a summary email to the manager at the end of each run with successes and failures.
Constants to Configure
Monthly revenue target per rep: £35,000 (configurable, single variable)
HubSpot Account Managers team ID: 163861030
HubSpot contact URL pattern: https://app.hubspot.com/contacts/25187088/record/0-1/{contact_id}
HubSpot deal URL pattern: https://app.hubspot.com/contacts/25187088/record/0-3/{deal_id}
Email Structure Claude Must Produce
The email follows this order:
Greeting
Monthly target block (with green/amber/red callout based on performance)
Today’s priority calls
Stale deals
Uncontacted leads (with red reassignment-warning callout)
Reminders
Sign-off: “Have a strong day. Kind regards,” — the manager’s Gmail signature appends automatically.
A fully-rendered example email will be attached to this brief. Claude should match its structure, tone, and formatting:
Bold section headings, no dashes around headings
HubSpot hyperlinks on every contact and deal name
Coloured callout blocks for emphasis on monthly target performance and the lead reassignment warning
Tech Stack
Zapier or n8n — freelancer’s choice. n8n preferred (cheaper at this volume, more flexible, can be self-hosted). Either is acceptable.
HubSpot API (existing connection)
Anthropic Claude API — model claude-sonnet-4-7
Gmail API via OAuth (so drafts land in the manager’s account)
Acceptance Criteria
Workflow runs reliably every weekday at 7:30 AM London time.
Reps are pulled live from the HubSpot Account Managers team — adding or removing a member from that team in HubSpot must update who receives the briefing on the next run, with no code changes required.
Each rep receives an email with accurate, current HubSpot data. Closed-won figures match HubSpot exactly.
All HubSpot links in the email open the correct contact or deal records.
Edge cases handled gracefully: rep with no open deals, rep with no uncontacted leads, rep newly added to the team, end-of-month wraparound.
If HubSpot or the Claude API fails for one rep, the workflow continues for the others and a summary error email is sent to the manager.
A test-mode toggle that diverts all output emails to the manager’s inbox for safe testing.
Deliverables
Working n8n workflow (exported JSON) or Zap (shared)
Setup documentation explaining how to: change the monthly target, modify the email structure or Claude prompt, swap the team ID, toggle test mode, view logs
A handover walkthrough call
A short bug-fix support window after go-live (to be agreed)
Notes for Applicants
This is a sales operations automation, not pure backend dev work. Strong candidates will have shipped at least one HubSpot + LLM API automation before, and be comfortable with HubSpot’s Search API filters, owner and team objects, and the difference between contact-, deal-, and user-level data. Familiarity with the Anthropic Messages API is required.
